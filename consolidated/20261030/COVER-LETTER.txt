Subject: [RFC PATCH 00/26] Apple M1 USB4 native PCIe storage and dock display integration

This downstream review series consolidates the measured M1 native PCIe storage
path and the Test128 dock-display path. It combines PCIe-C initialization,
DART/MSI safety, Type-C transitions, firmware-node port association and topology
notifications with DCP/DP-IN routing and display hotplug callbacks.

The ordinary NVMe driver is unchanged. AMDGPU, TTM, GPU audio and application
patches are not part of this series. Suspend remains explicitly deferred; the
existing reset ACK diagnostic ambiguity is not presented as solved.
